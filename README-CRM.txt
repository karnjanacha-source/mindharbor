MindHarbor CRM & Automation DEMO
Run START-WINDOWS.bat with Node.js 18+. Visit http://localhost:3000/#crm.
CRM: voluntary alias, expert/channel preference, opt-in reminders/marketing, daily educational activity points.
Workflow: booking/cancellation create simulated customer email + admin notification in demo-automation.json. No real messages sent.
Demo only: do NOT enter real patient, health or contact data. Not production-grade authentication or privacy.
Suggested No-Code deployment: Bubble/Softr frontend, Xano/Supabase backend with row-level security, Make automation, transactional email service and Calendar. Store opt-in and use minimal data.
