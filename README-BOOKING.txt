MindHarbor · ระบบจองคิวผู้เชี่ยวชาญสมมติ (ปรับปรุง โดยคงหน้าตาเดิม)

วิธีเริ่มต้น
1. ติดตั้ง Node.js 18+
2. เปิด START-WINDOWS.bat บน Windows หรือรัน node server.js ในโฟลเดอร์นี้
3. เปิด http://localhost:3000 ห้ามเปิด index.html ตรง ๆ เพราะจะไม่เชื่อมต่อฐานข้อมูลนัดหมาย
4. เลือกผู้เชี่ยวชาญจากโปรไฟล์หรือเมนูในกล่องจองคิว เลือกวันที่หรือกดค้นหาวันว่างถัดไป เลือกช่วงเวลาที่เปิด และกดยืนยัน
5. ระบบออกหมายเลขจองและเก็บรหัสสิทธิ์ในเบราว์เซอร์เพื่อดู/ยกเลิกนัดหมาย รวมถึงเพิ่มลงปฏิทิน (.ics)
6. เปิดเบราว์เซอร์อีกตัวที่ http://localhost:3000 เพื่อทดสอบการป้องกันจองซ้ำข้ามเบราว์เซอร์

ข้อมูลบันทึกใน demo-bookings.json บนเซิร์ฟเวอร์สาธิตเครื่องนี้ ไม่ได้จองแพทย์จริง
โปรไฟล์ ค่าบริการ และตารางทั้งหมดสมมติ ไม่มีระบบชำระเงินหรือส่งอีเมลจริง
ห้ามกรอกข้อมูลสุขภาพหรือข้อมูลส่วนบุคคลจริง และห้ามนำเซิร์ฟเวอร์สาธิตนี้ขึ้นอินเทอร์เน็ตสาธารณะ
ส่วนอื่นของเว็บไซต์และระบบ CRM คงเดิม
