# MindHarbor — GitHub-ready demonstration

เว็บไซต์ MindHarbor ตามต้นแบบเดิม พร้อมระบบจองคิวผู้เชี่ยวชาญสมมติ, CRM สาธิต และบันทึก Automation แบบจำลอง

> **โครงการสาธิตเท่านั้น:** โปรไฟล์แพทย์/ผู้เชี่ยวชาญ รีวิว ราคา และช่องทางติดต่อเป็นข้อมูลสมมติ ไม่ใช่บริการแพทย์จริง ห้ามนำข้อมูลสุขภาพจริงมากรอกในระบบสาธิตนี้

## เริ่มใช้งานบนเครื่อง

ต้องมี Node.js 18 ขึ้นไป

```bash
npm start
```

เปิด `http://localhost:3000` (บน Windows สามารถใช้ `START-WINDOWS.bat` ได้)

## อัปโหลดขึ้น GitHub

1. สร้าง repository ใหม่บน GitHub (แนะนำ **Private** ระหว่างพัฒนา)
2. แตกไฟล์ ZIP นี้ แล้วอัปโหลด **ไฟล์และโฟลเดอร์ภายใน** ไปที่ root ของ repository (รวม `assets/`, `server.js`, `package.json`)
3. Commit changes

หรือใช้ Git:

```bash
git init
git add .
git commit -m "Initial MindHarbor demo"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
git push -u origin main
```

## เผยแพร่เว็บไซต์

**GitHub Pages ใช้ได้เฉพาะหน้าเว็บแบบ static** จึงไม่รองรับ API จองคิวร่วมกันจาก `server.js` หากต้องการให้ระบบจองคิวทำงาน ต้องนำ Node.js server ไปโฮสต์บนบริการที่รองรับ Node.js พร้อม storage แบบถาวร หรือย้ายข้อมูลไปฐานข้อมูลส่วนกลาง เช่น PostgreSQL

`npm start` ใช้เปิดเซิร์ฟเวอร์ โดยค่าเริ่มต้นฟังที่ `127.0.0.1:3000` หากโฮสต์ต้องการให้รับการเชื่อมต่อภายนอกให้กำหนด `HOST=0.0.0.0` และ `PORT` ตามที่ผู้ให้บริการกำหนด

**ข้อจำกัด:** ปัจจุบันข้อมูลจองและ CRM เก็บใน JSON บนเครื่องเซิร์ฟเวอร์ เหมาะกับการสาธิตบนเซิร์ฟเวอร์เดียวเท่านั้น การเผยแพร่ต่อสาธารณะต้องเพิ่มการยืนยันตัวตน สิทธิ์แอดมิน การป้องกัน abuse, HTTPS, ฐานข้อมูลถาวร และการคุ้มครองข้อมูลตาม PDPA ก่อน

ไฟล์ `.gitignore` ป้องกันไม่ให้นำข้อมูลการจองที่สร้างระหว่างทดลองขึ้น GitHub โดยไม่ตั้งใจ
